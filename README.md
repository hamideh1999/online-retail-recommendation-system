# Online Retail Product Recommendation System

A hybrid product recommendation system built with Python using online retail transaction data.

## Overview

This project analyzes customer purchasing behavior and recommends products using purchase history, repeat-purchase patterns, and collaborative filtering.

## Key Features

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- RFM customer segmentation
- Hybrid product recommendation
- Time-based model evaluation

## Technologies

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Files

- `online retail product recommendation system.ipynb` — project implementation and analysis
- `report_english.pdf`- `report_farsi.pdf — project report

## How to Run

1. Download or clone this repository.
2. Install the required Python packages.
3. Download the dataset and place it at the path specified in the notebook.
4. Open the notebook in Jupyter Notebook and run the cells in order.
